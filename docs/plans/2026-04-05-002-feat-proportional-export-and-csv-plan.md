# feat: Proportional PNG export with bar lines + CSV export

## Overview

Enhance the existing song structure export feature (R3/R4 from origin). Two changes:

1. **PNG image**: Replace fixed 160×80px grid with proportional-width sections where width reflects bar count. Add light vertical bar lines inside each section block. Fit everything in one canvas.
2. **CSV export**: Replace the plain text "Copy as text" with a CSV format where each row represents one bar, suitable for loading into spreadsheets.

(see origin: docs/brainstorms/2026-04-05-bar-count-and-export-requirements.md — R3 and R4)

## Proposed Solution

### PNG — Proportional Layout

**Layout algorithm:**
- Sections flow left-to-right in order, wrapping to a new row when cumulative width exceeds canvas width
- Each section's width is proportional to its bar count relative to the total bars in that row
- Minimum section width: 60px (enough for a truncated name + bar count)
- If a section's proportional width < minimum, clamp to minimum; remaining sections share the leftover
- Canvas width: ~800px. Rows fill the full width.
- Row height: 70px with 8px gap

**Bar lines:**
- Light vertical lines inside each section block, one per bar boundary (N-1 lines for N bars)
- Color: `rgba(255, 255, 255, 0.08)` — subtle, won't compete with text
- If a section has >16 bars, draw every 4th bar line slightly brighter to maintain readability

**Section block content:**
- Section name (truncated to fit width)
- Bar count ("~N bars")
- Left color accent strip (existing)
- Time range in bottom-right (if width allows, otherwise omit)

**Fallback when `beatTimestamps` is empty:**
- Use time-duration-proportional widths (`endSec - startSec`) instead of bar count
- Bar lines are not drawn (no beat data)
- Bar count text shows nothing (existing behavior)

**Header/footer:** Same as current — title, artist, metadata line, "Generated by Shreddy" footer.

### CSV Export

**Format:**
```csv
bar,section,start_time,end_time
1,Intro,0:00,0:03
2,Intro,0:03,0:06
3,Intro,0:06,0:09
...
17,Verse 1,0:48,0:51
```

- **bar**: Global bar number (1-N across entire song)
- **section**: Section name for that bar
- **start_time**: Timestamp of the bar's first beat (M:SS)
- **end_time**: Timestamp of the next bar's first beat (or section end for last bar)
- Header row with column names
- Song metadata as a comment row or omitted (keep it simple for spreadsheet import)

**Fallback when `beatTimestamps` is empty:**
- One row per section (bar column empty, start/end = section start/end)

**UI change in SectionStrip.tsx:**
- Rename "Copy as text" → "Copy as CSV" with same Copy icon
- Same clipboard behavior, same "Copied!" feedback

### Implementation Units

#### Unit 1: CSV Export

**Goal:** Replace plain text export with CSV format.

**Files:** `src/lib/export-structure.ts`, `src/components/SectionStrip.tsx`

**Approach:**
- New function `copyStructureCSV(song: ExportSongData): string`
- For each section, enumerate bars by filtering `beatTimestamps` to section range, grouping by timeSignature
- Each group of N beats = 1 bar → output one CSV row
- Global bar counter across all sections
- Handle empty beatTimestamps: one row per section

**Patterns to follow:** Existing `copyStructureText()` function signature and data flow at `export-structure.ts:52-86`

**Verification:** Copy CSV from Shreddy, paste into Google Sheets — columns align, bar numbers are sequential, section names appear correctly.

**Execution note:** Test-first — write CSV generation, verify output string format manually.

#### Unit 2: Proportional PNG Layout

**Goal:** Section widths proportional to bar count, with bar lines.

**Files:** `src/lib/export-structure.ts`

**Approach:**
1. Calculate total bars across all sections
2. Determine rows by flowing sections left-to-right with wrapping
3. For each row, allocate width proportionally (with 60px minimum)
4. Draw sections with proportional widths
5. Draw bar lines inside each section: vertical lines at regular intervals
6. Adapt text rendering to available width (truncate name, omit time range if too narrow)

**Patterns to follow:** Existing `generateStructureImage()` at `export-structure.ts:93-213` — same Canvas API approach, same color scheme, same header/footer.

**Verification:** Export PNG for "Tears For Fears - Everybody Wants To Rule The World" — sections should visually reflect relative lengths (intro shorter than verse, solo shorter than chorus etc.). Bar lines visible but subtle.

**Execution note:** Implement after Unit 1. Iterate on layout visually.

### Edge Cases

| Case | Behavior |
|------|----------|
| No beat data | PNG: duration-proportional widths, no bar lines. CSV: one row per section |
| Section with 0 bars (Math.round → 0) | Treat as 1 bar minimum for layout purposes |
| Single section song | Full-width section block |
| 20+ sections | Wrap to multiple rows, each row independently scaled |
| Very short section (1-2 bars) | Clamp to 60px min width, show only name |
| Very long section (30+ bars) | Draw every 4th bar line slightly brighter |
